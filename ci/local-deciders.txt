# What a developer can decide before pushing, and what only CI can.
#
# Every required context on `main` gets a line here: either the local command that decides it, or
# NOT-LOCAL with the reason. `cargo xtask ci-spec local-coverage` checks BOTH directions -- a
# required context with no line is a red, and a line naming a context that is not required is a
# red. Same convention as `assurance/trusted-base.txt` ("everything trusted is listed") and
# `.clippy-unanalysed.txt`, and for the same reason: a set that only grows in one direction
# stops describing anything.
#
# WHY THIS FILE EXISTS. Measured 2026-09-20. Ten branches were pushed after `just prepush`
# reported every check green. CI then red on five of the eight it could judge -- a 62% miss rate
# -- and three of the five were gates that ALREADY EXISTED in this tree and were simply not in
# `scripts/prepush.sh`:
#
#   check-gate-defs-match-plan.sh   0 s   in the tree, not in the list
#   xtask ci-spec check             3 s   in the tree, not in the list
#   check-clippy-ratchet.sh        53 s   in the tree, not in the list
#
# None was a cost decision. There was no decision: nothing compared the gauntlet's list against
# the contexts it is meant to predict, so a gate added to CI simply never reached the fast path
# and every local green quietly meant less than it said.
#
# A line here is a CLAIM that running that command decides that context. The checker holds the
# claim to the two files -- the command must appear in `scripts/prepush.sh` -- so a decider that
# is declared and not wired is the same red as one that is missing. What it cannot check is that
# the command decides the SAME question the context does; that is a judgement, and it is why each
# line is short enough to read.
#
# PINNED may only GROW with the required set, and NOT-LOCAL may only SHRINK. Moving a context to
# NOT-LOCAL is a deliberate, dated act: it is a statement that the fast gauntlet has given up on
# predicting that gate.
#
# PINNED = 38
# NOT-LOCAL = 19

# --- NOT-LOCAL: CI decides, and the reason -----------------------------------
# Cost. Perturbs every gate and re-runs the pipeline: ~35 minutes. `assure probe-needles` in
# gatehouse is the cheap subset -- it catches a probe whose needle has moved, which is the
# failure mode that actually recurs -- but it does not decide this context.
Gates must fail on their own subject <- NOT-LOCAL: ~35 min, perturbs and re-runs every gate

# Cost. Mutation testing rebuilds the workspace per mutant.
Mutation Testing <- NOT-LOCAL: rebuilds per mutant
Fuzz <- NOT-LOCAL: time-boxed fuzzing, not a bounded check
Code Coverage (llvm-cov) <- NOT-LOCAL: instrumented rebuild of the workspace

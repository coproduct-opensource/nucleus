## (b) Gap between proved model and shipped enforcement path — what is in the TCB but unverified

1. **Extraction is of mirrors, not production.** Every EXT theorem sits on `nucleus-ifc-kernel/src/extracted/*.rs` restatements; `docs/PROOFS.md:123-125` admits extraction "relocates the model↔code gap into Rust". Bond = parity tests (exhaustive for small enums, proptest for `BTreeSet<String>`/Unicode). Aeneas `loop` combinator doesn't reduce (`verified-claims.md:316-321`), so loops (`sanitize_bytes`, `bytes_eq`, `has_prefix`, `Iter::fold`) are TEST or axiom.
2. **Hand-written externals in the "extracted" core**: `FunsExternal.lean` PartialOrd + hash stub; `CoreFuns.lean` curation is human-selected.
3. **Runtime `Kernel::decide()`** composes verified lattice/exposure logic with unverified time, budget, path/command string matching (FORMAL_METHODS.md:238-240); `decide_pure` proof is a hand model.
4. **Effect layer and I/O**: `RealEffects` raw primitives (`scripts/sealed-home-allowlist.txt`), cap-std, `std::process`, reqwest — trusted, grep-gated (`check-mediation.sh`, `check-sealed-home.sh`). Audit sinks are deliberately unmediated (mediated-set.md "the one that deserves scrutiny").
5. **Isolation TCB**: Firecracker device emulation, KVM/host kernel, seccomp BPF contents (EXTERNAL); iptables/dnsmasq application verified only by a boot probe on one arch; cgroup ordering UNPINNED; guest-init/tool-proxy as PID 1.
6. **Crypto**: `ring`/`ed25519-dalek` EUF-CMA, SHA-256 collision resistance as named hypotheses (`docs/PROOFS.md:96-100`); JWT signature check outside extraction (`verified-claims.md:440-441`).
7. **Verification toolchain**: rustc affine moves, Charon/Aeneas fidelity, Lean kernel + Mathlib, `native_decide` (Lean compiler + host evaluator) on 5 load-bearing theorems incl. `FlowGraphProofs.invariant_exploit_dag_blocked` and `IdentityMaterialNoninterference.delivery_is_flows_to_against_the_ceiling`; Kani 0.67 with `cfg(kani)` type narrowing (semantic divergences: permission digest omits extensions; `is_triggered` sets `ext_met=true`).
8. **Dylint lint soundness** (deny-set completeness, `dyn`/fn-pointer/FFI blind spots) is trusted; runs on 3 crates, cross-crate soundness "relative to running over the whole set".
9. **Dual stack**: sealed `DischargedBundle` runs alongside the legacy `DecisionToken` kernel/guard, not replacing it (`north-star-certificate.md:141-144`); obligation checks "vacuous on a clean session" (:149-153).
10. **Attestation / outside verification** (C9) NOT-YET: served SVID carries no DICE attestation; attested-cert producer is dead code (ratchet file 2026-08-08).

## Bottom line vs. the North Star
Clause 4 has genuine, CI-regenerated extracted proofs for five IFC axes, scope binding, declassification, credential/identity delivery, egress matching and the CK gate — but each is a theorem about a mirror, bound by tests, sitting under an unverified I/O layer, a hand-curated lattice bridge, and a partially-running Kani suite. Clauses 1, 2, 3 and 5 have almost no formal content: authorization expressiveness (time, budget, approvals, revocation, multi-principal) is HAND or TEST, and no ratchet measures the delegatable envelope growing. The house discipline (ledgers that demote, ratchets that only shrink) is unusually honest, yet at least nine documents carry numbers or statuses the tree no longer supports.

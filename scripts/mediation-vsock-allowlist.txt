# Mediation gate — VSOCK allowlist.
#
# Credentialed egress asks the HOST to perform a call, over vsock. A vsock
# `write_all` is invisible to the `.send()` net pattern, so without this pattern
# that egress left the gate's view at exactly the moment it began working.
#
# WHY THIS IS NOT REDUNDANT WITH THE TYPESTATE
#
# `broker_client::perform_line` takes an `Authority`, which is constructible only
# from a `DischargedBundle` whose constructor is private to the discharge module.
# So a TYPED perform with no discharge does not compile.
#
# That signature cannot see a hand-rolled frame: code that opens its own
# VsockStream, formats the JSON itself and writes it never touches `perform_line`
# and never needs an `Authority`. The typestate covers the typed path; this
# covers the raw-primitive escape. Neither subsumes the other, and each is
# perturbed on its own — a green from both together would otherwise say nothing
# about which one is load-bearing.
#
# ONE EGRESS ENTRY and two other protocols. `broker_client` performs
# EGRESS for the agent and must spend an authority to do it. `spend_shipper`
# (#2541) ships clearing evidence and the proxy's signed spend records to the
# node's receipt collector. It reaches no external upstream and performs no
# agent-requested operation. Missing or invalid accounting prevents a refund;
# the node retains the full allocation. This is trusted accounting telemetry.
# Another entry on the agent egress path would also have to spend authority;
# the accounting and shadow-decision protocols do not perform egress.
file:crates/nucleus-tool-proxy/src/broker_client.rs
file:crates/nucleus-tool-proxy/src/spend_shipper.rs
#
# 2026-10-02 (#2702, P8): the decision channel. It is not egress: it carries a
# question (operation, subject, digest), a taint raise and the guest's own
# outcome, and the host performs nothing on it, so there is no authority to
# spend. It is where the deciding moves to the host (P9), which is the opposite
# of an escape from mediation. The connect lives in exactly one function,
# `host_decide::vsock_dialer`.
